# WOR Gameplay Framework

Addon genérico de gameplay para Godot 4.7+. O núcleo M1 oferece tags hierárquicas,
atributos data-driven, efeitos instantâneos/temporários/infinitos/periódicos,
stacking, contexto transitório e `AbilitySystemComponent`. O M2 adiciona abilities,
specs, custos, cooldowns, eventos e tasks runtime canceláveis.
O M3 fornece catálogo/editor de tags, browsers e validação de Resources e debugger
runtime somente leitura para o ASC.

O addon não depende de nenhuma classe ou regra específica de Whiskers of Rage.
Consulte `docs/manuals/use-gas-core.md` e `docs/manuals/use-gas-editor-tools.md` no
projeto hospedeiro para configuração e uso.
